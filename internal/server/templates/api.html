API

HTTP-Schnittstelle für Dokumentlisten, Uploads und Statusprüfungen

Authentifizierung

Alle API-Endpunkte verwenden dieselbe Basic-Auth-Konfiguration wie die Weboberfläche.

OpenAPI

Die maschinenlesbare Spezifikation nach OpenAPI 3.1 steht als YAML-Datei bereit.

GET /api/openapi.yaml

Status

GET /healthz

Liefert {"status":"ok"}, wenn der Dienst erreichbar ist.

Upload

POST /api/upload

Akzeptiert multipart/form-data. Dateien werden über das Feld files übertragen; mehrere Dateien sind möglich.

curl -u admin:change-me \
  -F "files=@rechnung.pdf" \
  http://127.0.0.1:8080/api/upload

Antworten enthalten die Arrays uploaded, duplicates und errors.

Tags

GET /api/tags

Liefert alle verfügbaren Tags inklusive Beschreibung, Farbe, Gruppenmodus, Detailtag-Status, Löschschutz und aktueller Dokumentanzahl.

curl -u admin:change-me \
  http://127.0.0.1:8080/api/tags

Benutzerdefinierte Felder

GET /api/fields

Liefert alle Felddefinitionen inklusive ID, Label, Position und Auto-Vervollständigung.

curl -u admin:change-me \
  http://127.0.0.1:8080/api/fields

Dokumente

GET /api/documents

Liefert eine paginierte Dokumentliste mit denselben Filtern wie die Oberfläche.

curl -u admin:change-me \
  "http://127.0.0.1:8080/api/documents?q=rechnung&tags=steuer&field_3=ACME&from=2026-01-01&to=2026-12-31&sort=date&dir=desc&page=1&page_size=50"

Filterparameter: q, wiederholtes tags, field_<id> für Werte benutzerdefinierter Felder, from, to, year, sort, dir, page, page_size und optional trash=1. Suchbegriffe unter drei Zeichen werden wie in der UI ignoriert; Feldwertfilter suchen case-insensitive nach Teiltreffern im jeweiligen Feld.

Sortierungen: upload_date, date, name, title, size und deleted_at. Richtungen: asc oder desc.

Virtuelle Ordner

GET /api/folders

Liefert die tag-basierten virtuellen Ordner fuer externe Clients. Der Endpunkt nutzt wiederholtes tags, page und page_size; Datums-, Such- und Papierkorbfilter werden fuer normale Tag-Pfade ignoriert.

curl -u admin:change-me \
  "http://127.0.0.1:8080/api/folders?tags=steuer&page=1&page_size=500"

Ohne Tags enthaelt die Antwort nur weitere Ordner. Wenn Suchfavoriten existieren, ist 00 Suchfavoriten der erste Ordner. Mit Tags enthaelt sie weitere passende Ordner und die paginierten Dokumente fuer die Tag-Auswahl.

Der virtuelle Pfad tags=00 Suchfavoriten listet Suchfavoriten als Ordner; tags=00 Suchfavoriten&tags=Favoritname liefert die Dokumente des gespeicherten Filtersets.

Dokumente enthalten unter anderem document_date, uploaded_at, updated_at, size_bytes, sha256, download_url und thumbnail_url.

WebDAV

{{.WebDAVPath}}/

WebDAV-Zugriff auf dieselbe virtuelle Ordnerstruktur. Der Pfad ist ueber webdav.path oder BEARSTACK_WEBDAV_PATH konfigurierbar. Lesen bleibt unveraendert moeglich; zusaetzlich ist PUT als reiner Erstellungsweg erlaubt (kein Ueberschreiben). DELETE, MKCOL, MOVE, COPY und weitere Schreibmethoden bleiben gesperrt.

Beim Upload per PUT uebernimmt das neue Dokument die Tags der aktuellen Tag-Hierarchie. Uploads in 00 Suchfavoriten sind nicht erlaubt.

webdav://127.0.0.1:8080{{.WebDAVPath}}/

Dokument herunterladen

GET /api/documents/{id}/download

Liefert die Originaldatei als Attachment. Dieser API-Alias verwendet dieselbe Authentifizierung wie die Weboberflaeche.

Dokument-Vorschaubild

GET /documents/{id}/thumbnail

Liefert ein JPEG-Vorschaubild, sofern BearStack eines erzeugen kann. Bilddateien koennen direkt als Inline-Vorschau geliefert werden.

Dokument-Tags

POST /documents/{id}/tags

Ersetzt die Tags eines aktiven Dokuments. Tags werden als wiederholtes Formularfeld tags gesendet; die Antwort enthält die gespeicherten Tags als JSON.

curl -u admin:change-me \
  -d "tags=steuer" \
  -d "tags=rechnung" \
  http://127.0.0.1:8080/documents/12/tags
